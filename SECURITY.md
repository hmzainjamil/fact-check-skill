# Security and data handling

## Scope

This note covers use of the static fact-checking guidance. No executable app or source-fetching service is included.

## Submitted material

Claims, URLs, screenshots, and documents submitted to an assistant or browsing tool may contain personal, confidential, or sensitive information. Review and minimize material before submission. Use only sources and content you are authorized to share.

## External tools

The skill instructs a reviewer to investigate web sources. Any browsing or model tool used may transmit queries or content to an external service under that service's current terms. This repository does not control provider selection, access, retention, logging, or deletion. Do not submit credentials, private records, or sensitive personal data without an approved basis and suitable controls.

## Output handling

Fact-check cards and summaries can contain sensitive allegations or quoted claims. Preserve source context, avoid unnecessary personal details, label uncertainty, and review before sharing. A verdict is not proof of truth and can cause harm if unsupported.

## Limits

No security tests, privacy controls, source sanitization, access controls, retention policy, or deletion mechanism are implemented here. The score described in the skill is a heuristic, not a safety rating.
